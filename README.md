# Proyecto: Solución para una tienda de un barrio

 ### Descripción:
Este proyecto permite agregar, mostrar, ordenar por lista, buscar, modificar, eliminar, mostrar estadistica de los productos de una tienda de un barrio.
## Analisis:

### Entrada:
- `Nombre` = valor,
- `Precio` = valor,
---

### Procesamiento:
#### Agregar, Modificar, Buscar, Eliminar, Estadisticas
---
### Salida
####  Mostrar productos, Estadisticas, Listas ordenadas, Busquedas, Resultados de operaciones
---

## Tenologia utilizadas:

 - C#

 - .Net

 - Visual studio community

 - Aplicación de consola
